# legacy/

Copia exacta de la app original (sala única, sin TypeScript, sin build).
Se conserva intacta y funcional (`npm install && npm start` dentro de esta
carpeta) durante toda la migración, como referencia y como red de
seguridad. Se elimina recién cuando la nueva app cubra toda su
funcionalidad y lo confirmes vos explícitamente — ninguna fase la borra
automáticamente.
